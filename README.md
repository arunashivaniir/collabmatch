# CollabMatch

CollabMatch is a full-stack collaboration platform built with Next.js and Supabase that helps students find teammates based on skills, goals, and collaboration interests.

## Tech Stack

* Next.js 16
* React
* Tailwind CSS
* Supabase
* PostgreSQL

## Features

* User Authentication
* Secure Onboarding Flow
* Dynamic Skills & Needs Tags
* Profile Creation System
* Collaboration Matching
* Protected Routes
* Row Level Security (RLS)

## Built With

* Next.js App Router
* Supabase Auth
* PostgreSQL Database
* Tailwind Responsive UI
* React State Management
